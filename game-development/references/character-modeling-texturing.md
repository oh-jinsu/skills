# 캐릭터 모델링과 텍스처 페인팅

디자인 이미지에서 리깅을 준비할 수 있는 로우폴리 캐릭터를 만들고, 다운로드한 메시를 부위별로 새로 칠하는 절차다. 승인된 비례와 현재 요청 범위를 우선한다. 이미 완료된 단계는 다시 생성하지 않는다.

## 1. 디자인과 메시를 먼저 확정한다

- 실제 레퍼런스에서 머리/몸 비례, 팔다리, 실루엣, 의상 경계를 관찰한다. 기본 도형을 눈에 띄게 이어 붙인 결과를 최종 캐릭터로 제출하지 않는다.
- 사용자가 비례를 승인했다면 게임 캐릭터다운 표현을 개선한다는 이유로 비례까지 바꾸지 않는다. 디자인 이미지를 먼저 맞춘 다음 메시 생성으로 넘어간다.
- 리깅용 입력은 정면의 중립적인 T 포즈로 만든다. 팔은 옆으로 펴고 손과 몸, 양다리가 겹치지 않게 한다. 장식·소품이 관절이나 손을 가리지 않게 한다. T 포즈 생성은 리깅 완료를 뜻하지 않는다.
- Tripo 등 사용자가 선택한 생성 도구에서 메시를 생성한다. 서비스 화면과 요금은 현재 상태로 확인하고, 이미 승인된 작업과 계정을 재사용한다. 로그인 정보나 브라우저 프로필 경로를 스킬에 고정하지 않는다.
- 삼각형 예산은 레퍼런스와 필요한 형태에 맞춘다. 500개에서 형태가 무너진다면 같은 디자인으로 1,000개 수준을 비교할 수 있지만 이를 모든 캐릭터의 고정 예산으로 삼지 않는다. 서비스에 입력한 목표와 다운로드한 모델의 실제 삼각형 수를 구분한다.
- 크레딧을 아낀다. 선택한 결과를 한 번 다운로드하고 재사용한다. 같은 텍스처를 고치려고 매번 유료 모델을 재생성하거나 내보내지 않는다. 이미 승인된 유료 작업은 중복 확인 없이 진행하되, 새 구매나 무제한 반복 실행으로 범위를 넓히지 않는다. 실질적인 개선이 없으면 원인을 설명하고 추가 유료 반복을 멈춘다.

## 2. 원본과 변경 불변 조건을 기록한다

- 원본 GLB와 원본 텍스처를 보존하고, 새 작업은 별도 버전으로 저장한다. 사용자가 기존 페인팅을 무시하라고 하면 예전 컬러 아틀라스·투영 그림을 새 색상 입력으로 쓰지 않는다. 원래 디자인, 승인된 메시와 부위 선택은 재사용할 수 있다.
- 텍스처 작업에서는 정점 위치, 비례, 삼각형, 코너별 UV를 유지한다. 몰래 리메시·단순화·서브디비전·UV 재배치를 하지 않는다. UV 경계의 중복 정점도 임의로 합치지 않는다.
- 좌표계, 앞 방향, 모델 중심·바운딩 박스, 정사영 카메라와 해상도를 기록한다. 모델별 설정을 사용하고 이전 캐릭터의 숫자나 면 번호를 복사하지 않는다.

## 3. 칠하기 전에 부위별 면 마스크를 만든다

머리카락, 얼굴·귀·턱·목 피부, 재킷, 드레스, 손, 다리, 신발, 소매 끝처럼 실제 재질 경계에 따라 나눈다. 이는 한 캐릭터의 예시이며 부위 수는 디자인에 맞춘다.

1. 연결 구조, 형상, 여러 방향의 원본 표면을 참고해 면을 선택한다. 색상 임계값이나 높이 기준은 초기 후보를 찾는 보조 수단으로만 쓰고, 검수한 면 목록으로 확정한다. 검은 눈을 머리카락으로, 어두운 턱을 다른 재질로 오분류하지 않는다.
2. 이름 있는 재질 슬롯과 FACE 도메인 속성 등에 정확한 면 소속을 저장한다. JSON 등으로 면 목록을 남길 수 있지만 이는 해당 토폴로지에만 유효하다. 공유 경계 정점이 있는 버텍스 그룹만으로 정확한 면 마스크를 대신하지 않는다.
3. 경계에 Mark Seam을 지정한다. **Seam은 UV 절개 경계 표시이며 페인팅 마스크가 아니다.** Texture Paint의 Face Selection Masking 또는 면별 재질 마스크를 함께 사용한다. 기존 UV를 유지하는 작업에서는 Seam을 표시했다고 다시 Unwrap하지 않는다.
4. ID 컬러를 입힌 실제 메시를 회전하고 부위를 단독 표시해 선택을 점검한다. 귀·턱·목은 피부에, 머리카락 안쪽·잔머리는 머리카락에 포함되는지 확인한다. 재킷의 라펠 같은 하위 구분은 별도 면 속성으로 저장할 수 있다.
5. 부위 마스크가 확정된 뒤 페인팅한다. 미리보기를 위해 메시를 실제로 분리할 필요는 없다.

## 4. 부위 안에서 일관된 색과 그림을 만든다

- 피부 바탕색은 얼굴·귀·턱·목에서 연속되게 만든다. 머리카락·옷·신발도 각 영역에 하나의 일관된 색 체계를 사용한다. 바탕과 부드러운 공간 음영, 국소 그림을 분리하면 수정하기 쉽다.
- 얼굴에는 눈·눈썹·입·볼터치처럼 필요한 특징을 국소적으로 얹는다. 원본 메시에서 렌더한 중립 템플릿을 편집 대상으로 삼고, 디자인 참조는 별도 역할로 명시한다. 생성된 그림이 프레이밍과 위치를 바꿀 수 있으므로 실제 랜드마크로 정렬한다.
- 얼굴 전체에 배경과 머리카락까지 포함된 그림을 그대로 투영하면 사선에서 회색 쐐기나 턱 얼룩이 드러날 수 있다. 필요한 특징 주변에만 부드러운 마스크를 적용하고, 나머지는 공통 피부 바탕으로 연결한다. 정면에서 가려지는 작은 면도 확인한다.
- 여러 뷰의 그림을 사용할 때는 같은 스케일·중심·색상을 유지한다. 부위 마스크에 더해 카메라에서의 가시성, 표면 방향과 가림을 고려하고 접합부를 부드럽게 섞는다. 앞·뒤 투영 두 장만으로 전체를 덮거나, 보이지 않는 면을 반대편 그림으로 채우지 않는다.
- 머리카락은 정수리·옆면·안쪽에서도 같은 재질을 유지한다. 연속적인 공간 좌표의 색/가닥 음영이나 정렬된 다방향 그림을 사용할 수 있다. 회전 경계나 극점에 반복 무늬가 몰리지 않는지 본다.
- 재킷·드레스·신발에는 재질 구분, 절제된 명암과 접촉 음영을 담는다. 단색과 실시간 조명만으로 마무리하지 않는다. 안감, 소매 안쪽, 밑창도 실제 해당 면에 칠한다.
- 래스터 그림의 생성·편집은 사용 가능한 이미지 생성 도구와 그 지침을 따른다. Blender 재질 노드로 색·음영을 만들고 UV에 베이크하는 방법도 사용할 수 있다. 사용한 프롬프트, 이미지, 마스크와 카메라 정의를 저장한다.
- 빠진 안쪽 면이나 관절 형상 문제는 텍스처로 고칠 수 없다. 페인팅 오류와 형상 문제를 구분하고, 모델 수정은 요청된 범위에서 별도로 진행한다.

## 5. 기존 UV에 굽고 14방향으로 확인한다

- 부위별 마스크를 적용한 색상을 기존 UV의 새 컬러 아틀라스로 베이크한다. 해상도는 게임 카메라에서 필요한 선명도로 정한다. 예를 들어 작업용 2K 텍스처를 쓸 수 있지만 저해상도 목표를 자동으로 상향하지 않는다.
- UV 조각 사이의 패딩과 밉맵, 필터링에 따른 색 번짐도 확인한다. 면 마스크가 맞아도 UV 중첩이나 패딩 때문에 경계가 섞일 수 있다. 마스크를 계속 조정하기 전에 투영 문제인지 UV 샘플링 문제인지 구분한다.
- **6면:** 정면·후면·좌측·우측·위·아래의 정사영.
- **사선 8방향:** 모델을 감싼 상자의 위쪽 네 꼭짓점과 아래쪽 네 꼭짓점에서 중심을 바라본다. 정수리와 머리카락 밑처럼 축 방향에서 가려지는 부분을 드러내기 위한 검수다.
- 고정된 14장 사이도 연속 회전한다. 귀/턱/목 경계, 정수리, 머리카락 안쪽, 겨드랑이, 손목과 소매 안쪽, 치마 안감, 다리 사이, 발목, 밑창을 확대한다. 중요한 가려진 표면이 남으면 그 부위에 맞춘 카메라를 추가한다.
- 검수 대상은 그림이 아니라 **최종 텍스처가 적용된 실제 메시**다. 조명이 약한 상태나 컬러 텍스처만 보이는 뷰도 확인해서 조명으로 가려진 이음새를 찾는다. ID 컬러는 영역 확인용이고 최종 페인팅 결과가 아니다.
- 문제를 고친 뒤 영향받은 각도를 다시 확인한다. 사용자가 현재 검수를 마치고 저장·다음 작업을 요청하면 불필요한 재검수나 미술 반복을 이어가지 않는다.

## 6. 편집본과 사용 가능한 모델을 함께 남긴다

- 텍스처가 포함된 GLB, 부위 선택·Seam·이미지가 유지된 Blender 편집본, 새 컬러 아틀라스를 저장한다. 필요하면 베이크 전 재질/투영 원본도 따로 보존한다.
- 내보낸 GLB를 다시 읽어 모든 메시의 삼각형 수와 월드 좌표, 코너별 UV를 원본과 비교한다. 수치 오차 허용값을 명시한다. 재질 분리 때문에 생긴 정점 중복이나 순서 변경은 면의 위치·UV가 같은지로 판단한다.
- 재현에 필요한 면 목록, 프롬프트, 카메라, 베이크 설정과 스크립트, 실제 검수 이미지를 프로젝트에 남긴다. 다른 모델에 특정 면 번호나 계정·브라우저 ID를 고정한 스크립트를 그대로 적용하지 않는다.
- 결과에서는 확인한 각도, 유지한 형상/UV, 남은 문제와 추가 유료 사용량을 짧게 알린다. 전체 작업 과정을 반복 설명하거나 완벽하다고 단정하지 않는다.
